# Olius — Desenvolvimento Front-end

## Sobre o projeto

O **Olius** é uma plataforma digital desenvolvida com o objetivo de facilitar o descarte correto do óleo de cozinha usado, conectando cidadãos, estabelecimentos, pontos de descarte e coletores parceiros.

O projeto busca incentivar práticas mais sustentáveis por meio da tecnologia, contribuindo para a logística reversa e para a redução dos impactos ambientais causados pelo descarte inadequado do óleo.

**Slogan:** O futuro em cada gota.

## Objetivo deste repositório

Este repositório reúne os arquivos de desenvolvimento front-end do Olius, com foco na estruturação e estilização das páginas da plataforma.

Aqui estão organizados os códigos responsáveis pela interface visual, incluindo a disposição dos elementos, a identidade visual e a experiência de navegação dos usuários.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas e organização dos conteúdos.
- **CSS3:** estilização dos elementos, layouts, cores, tipografia e responsividade.

## Identidade visual

A interface do Olius segue uma identidade visual moderna, minimalista e tecnológica, utilizando tons claros e amarelos como principais elementos da composição.

O design foi pensado para transmitir inovação, sustentabilidade e facilidade de uso, mantendo uma experiência visual consistente em todas as páginas.

## Organização dos arquivos

Os arquivos estão organizados de acordo com suas respectivas funções, facilitando a manutenção e a continuidade do desenvolvimento do projeto.
